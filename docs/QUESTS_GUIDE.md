# Руководство по системе квестов FTB Quests

## 1. Структура файлов
- `config/ftbquests/quests/chapters/*.snbt` — ветки заданий.
- `config/ftbquests/quests/reward_tables/*.snbt` — таблицы случайных и фиксированных наград.
- `config/ftbquests/quests/chapter_groups.snbt` — группировка глав.

## 2. Пользовательские таблицы наград
Каждая тематическая ветка привязана к отдельной таблице наград по 64-битному ID:
- **Магическая награда (`magic_loot.snbt`)**: `6524608693172600834L` (Hex `5A8C11099EFA8002`)
- **Инженерная награда Create (`create_loot.snbt`)**: `6524608693172600836L` (Hex `5A8C11099EFA8004`)
- **Награда хранилищ (`storage_loot.snbt`)**: `6524608693172600833L` (Hex `5A8C11099EFA8001`)
- **Награда цифровых сетей (`refined_storage_loot.snbt`)**: `6524608693172600835L` (Hex `5A8C11099EFA8003`)

## 3. Сброс незачтённых наград
Если игрок нажал «Забрать» до применения патча (когда выпало 0 предметов):
1. Администратор прописывает `/ftbquests editing_mode true`.
2. Открывает квест в интерфейсе, нажимает правой кнопкой мыши по награде и выбирает сброс (Reset Progress).
3. Игрок забирает награду повторно.
