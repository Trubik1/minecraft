# История изменений Steampunk & Swords

## Версия 1.0.2 (31 октября 2026)
### Квесты и награды
- Исправлены 64-битные ID лут-таблиц во всех 192 случайных наградах (FTB Quests).
- Добавлены тематические дропы для магии, Create, хранилищ и Refined Storage.
- Восстановлены все 100+ стандартных рецептов семян Mystical Agriculture на Алтаре Наполнения (Infusion Altar).

### Лаунчер и мультиплеер
- Поддержка параллельного запуска нескольких окон игры с разных ников одновременно.
- Полноценный выбор и валидация рабочей директории в настройках лаунчера.
- Добавлен мод SkinRestorer для установки пользовательских скинов по команде `/skin set`.

### Производительность
- Интегрирован мод Chunky для предгенерации мира и устранения фризов при исследовании карты.
- Оптимизированы параметры сборщика мусора G1GC.
