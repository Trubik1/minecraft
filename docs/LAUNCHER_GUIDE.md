# SteampunkLauncher — Руководство пользователя

## 1. Одновременный запуск нескольких окон
Лаунчер поддерживает одновременный запуск нескольких клиентов с разными никами:
- Запустите первое окно с ником игрока 1.
- Нажмите «Сменить аккаунт» или запустите второй экземпляр `SteampunkLauncher.exe` с другим ником.
- Оба окна будут работать независимо друг от друга.

## 2. Выбор папки игры
- По умолчанию файлы устанавливаются в `D:\SteampunkLauncher` (или в выбранную в настройках папку).
- В настройках можно указать любую директорию на диске с достаточным объёмом свободного места (требуется от 10 GB).

## 3. Скины (SkinRestorer)
- В сборку встроен мод SkinRestorer.
- Для установки любого лицензионного скина введите команду прямо в чате:
  `/skin set <ник_игрока_со_скином>`
- Скин сразу отобразится у вас и у всех игроков на сервере.

## 4. Ложное срабатывание Windows Defender (0x800700E1)
Лаунчер не имеет платной цифровой подписи, поэтому Защитник Windows может временно заблокировать файл:
1. Откройте **Безопасность Windows** -> **Защита от вирусов и угроз** -> **Журнал защиты**.
2. Найдите заблокированный файл `SteampunkLauncher.exe` и нажмите **Разрешить на устройстве**.
