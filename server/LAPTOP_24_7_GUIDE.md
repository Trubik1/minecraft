# Инструкция: Запуск сервера 24/7 на ноутбуке (i3 3-го поколения, 12 ГБ ОЗУ)

Этот гайд написан специально для настройки 24/7 сервера **Steampunk & Swords** (Minecraft 1.21.1 + NeoForge 21.1.264) на слабом ноутбуке.

---

## 1. Настройка Windows на ноутбуке для 24/7 работы

Ноутбук не должен уходить в сон и сбрасывать частоты при закрытой крышке:

1. **Электропитание**:
   * Нажмите `Win + R`, введите `powercfg.cpl` и нажмите Enter.
   * Выберите схему **«Высокая производительность»** (или сбалансированная).
   * Слева нажмите **«Действие при закрытии крышки»**.
   * Для пункта «При питании от сети» выберите: **«Действие не требуется»**.
   * В настройках перехода в спящий режим поставьте: **«От сети: Никогда»**.
2. **Охлаждение**:
   * Поставьте ноутбук на твердую ровную поверхность (не на диван/кровать/ткань).
   * Желательно приподнять заднюю часть ноутбука на 1-2 см (подложить под ножки ластики или крышки от бутылок) либо использовать охлаждающую подставку.

---

## 2. Установка Java 21

Для Minecraft 1.21.1 необходима Java 21:
* Скачайте и установите **Eclipse Adoptium Temurin 21 (x64)**: https://adoptium.net/temurin/releases/?version=21
* При установке обязательно включите пункты **«Set JAVA_HOME»** и **«Add to PATH»**.

---

## 3. Подготовка папки сервера

1. Запустите инсталлятор **NeoForge 21.1.264**:
   * Выберите **Install server** и укажите папку для сервера.
2. Скопируйте из сборки клиента папки:
   * `config/`
   * `defaultconfigs/`
   * `kubejs/`
3. Папка `mods/`:
   * Скопируйте моды, **НО удалите чисто клиентские** (список в `server/client-only.txt`: `sodium`, `iris`, `entityculling`, `betterf3`, `better-advanced-tooltips`, `dynamic-fps`, `immediatelyfast`, `smoothswapping`, `inventoryparticles`, `mousetweaks`, `createschematichelper`).
4. Скопируйте файлы:
   * `server/server.properties`
   * `server/start-24-7.bat`

---

## 4. Как открыть сервер друзьям без белого IP (Playit.gg)

Вам **не нужно** настраивать роутер, открывать порты или ставить Hamachi/Radmin.

1. Зайдите на сайт https://playit.gg и скачайте программу для Windows (`playit-windows-x86_64.exe`).
2. Запустите её на ноутбуке.
3. В консоли появится ссылка — откройте её в браузере, чтобы привязать бесплатный аккаунт.
4. Добавьте туннель: **Minecraft Java** -> порт `25565`.
5. Playit выдаст вам публичный адрес, например:
   `steampunk-swords.gl.joinmc.link:38421` (или похожий).
6. Этот адрес впишите в `server.txt` на GitHub, и все игроки смогут подключаться автоматически в 1 клик через лаунчер!

---

## 5. Самое главное для i3: Предгенерация мира (Chunky)

Чтобы слабый двухъядерный процессор не зависал, когда игроки бегают и открывают новые территории:

1. Убедитесь, что в папке `mods` сервера лежит мод **Chunky** для 1.21.1 NeoForge.
2. Запустите сервер через `start-24-7.bat`.
3. В консоли сервера введите по очереди команды:
   ```text
   chunky radius 2500
   chunky start
   ```
4. Сервер сгенерирует мир радиусом 2500 блоков (квадрат 5000x5000) заранее. Оставьте на пару часов.
5. После завершения процессор во время игры будет отдыхать, потому что чанки будут мгновенно считываться с диска, а не генерироваться заново.

---

## 6. Автозапуск при включении ноутбука (опционально)

Если свет моргнет и ноутбук перезагрузится:
1. Нажмите `Win + R`, введите `shell:startup`.
2. Создайте ярлык для `start-24-7.bat` и для `playit.exe`.
3. Теперь при каждом старте ноутбука сервер и туннель поднимутся автоматически!
